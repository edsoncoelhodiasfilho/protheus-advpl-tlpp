# Laboratório de Estudos: Ecossistema TOTVS Protheus (ADVPL / TL++)

Este repositório reúne meus projetos práticos, códigos de estudo e scripts de infraestrutura voltados ao ecossistema **TOTVS Protheus**. O objetivo é consolidar minha transição técnica para o desenvolvimento e suporte N3, aplicando meus **18 anos de bagagem em TI de Varejo**.

## 🚀 Diferenciais Técnicos Aplicados neste Lab
- **Infraestrutura Linux:** Automação de configurações do `appserver.ini` e `dbaccess.ini` via Shell Script.
- **Banco de Dados Oracle:** Queries otimizadas e análise de dicionário de dados (Tabelas SX).
- **Integração Híbrida:** Uso de **Python** para testes de carga e consumo de APIs REST geradas em **TL++**.

## 🛠️ Conteúdo do Repositório

### 1. Infraestrutura e Banco de Dados (`/01-infra-e-arquitetura`)
- Scripts automatizados para deploy do Application Server em ambiente Linux.
- Validações de conexões OCI/ODBC e queries Oracle para monitorar o comportamento do DBAccess.

### 2. Desenvolvimento ADVPL e TL++ (`/02-advpl-basico` e `/03-mvc`)
- Implementação de **Pontos de Entrada (PE)** e Gatilhos para customização de regras de negócio de varejo.
- Telas construídas utilizando o padrão oficial **MVC (Model-View-Controller)** da TOTVS (`FWMBrowse`, `FWFormModel`).

### 3. Integrações e APIs (`/04-api-rest`)
- Desenvolvimento de endpoints RESTful nativos em Protheus para integração de dados de faturamento.
